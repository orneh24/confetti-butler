Other Confetti projects
A small button for each URL that is filled in appears at the right of the top menu on every page and opens that project in a new tab. Only http:// or https://. Leave a field empty to remove its button. The server connects to one of these addresses only for the syslog pull below, and only if you switch that on.
Syslog from other servers
Lets a device log to one Confetti server only. This server then reads the other one's own messages every few seconds (nothing it pulled itself is passed on) and skips a message it already has. Switching a server on starts from its newest message; its history is not copied. Set its URL in the section above first. Alert rules see a pulled message like any other.
